# Sudoku CSP Solver (backtracking / AC-3 / MAC / MRV)
- csp.py: mô hình CSP, 4 thuật toán, sinh đề, kiểm tra nghiệm duy nhất
- benchmark.py: sinh 3x30 đề và chạy 4 phiên bản; analysis.py: đề tham chiếu, AC-3 một mình, đầu vào lỗi, log
- figs.py: vẽ biểu đồ; main.py: giao diện dòng lệnh hiển thị từng bước
Chạy: python benchmark.py && python analysis.py && python figs.py
